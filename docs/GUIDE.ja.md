# Atelier AI 使い方ガイド

[한국어](GUIDE.md) · [English](GUIDE.en.md)

## このツールは何ですか？

Atelier AIは**画像生成専用のデスクトップアプリ**です。Webサービスではなく自分のパソコンで直接動くプログラムなので、生成した画像が外部サーバーに送信されることはありません。完全無料のオープンソース（MIT）です。

こんな方に向いています：

- アニメスタイルの画像を自分で生成してみたい方
- 英語の文章より**Danbooru式タグ**（`1girl, long hair`など）でプロンプトを書く方
- Anima系モデルを使う方
- 初心者でも難しくなく使いたい方

## 画面構成

左のメニュー6つがすべてです。

| メニュー | 内容 |
|---|---|
| 画像を作る | テキストプロンプトから画像を生成。バッチキュー・X/Yプロット・Hires Fixもここ |
| 画像を編集 | インペイント（一部を描き直し）・アウトペインティング（キャンバス拡張）・ポーズ指定生成 |
| モデルと学習 | チェックポイント・LoRA・ControlNetの管理、自分の画像でLoRA学習 |
| ライブラリ | 気に入った結果を集めておく場所 |
| 作業履歴 | これまでの生成履歴と設定値 |
| 設定 | 生成のデフォルト値・言語（한국어/English/日本語）・更新 |

## 初めて使う流れ

1. **モデルを入れる**：チェックポイント（`.safetensors`）をモデルフォルダに入れます。フォルダの場所は設定で確認できます。モデルがなくてもアプリは開きます。
2. **プロンプトを書く**：「画像を作る」で描きたいものをDanbooru式タグで書きます。タグに困ったら**プロンプトヘルパー**を開いてみてください。おすすめタグ・画風・構図のチップがあり、🔍検索タブでは日本語・韓国語で検索すると英語タグが見つかります。（`長い髪` → `long hair`）
3. **生成ボタン**：1枚ずつ生成しながらステップ・CFG・サンプラーを調整します。すべての設定項目に説明と推奨値が表示されます。

## 知っておくと便利な機能

- **バッチキュー**：プロンプトを最大200件までリストに入れると、1枚ずつ順番に生成します。1件失敗しても次に進みます。
- **X/Yプロット**：サンプラー・CFG・ステップ・シードをグリッドで比較できます。（最大36マス）
- **Hires Fix**：小さく生成した後、大きく整えて高解像度にします。（単発生成専用）
- **顔補正**：ギャラリーで`✨ 얼굴 보정`（顔補正）を押すと顔を検出して描き直します。
- **アップスケール**：RealESRGANで拡大します。元画像との混ぜ具合をスライダーで調整できます。
- **アウトペインティング**：ギャラリーで`🖼️ 확장`（拡張）を押すと、上下左右にキャンバスを広げられます。
- **LoRA学習**：自分の画像15〜30枚でキャラクター・画風LoRAを直接作れます。キャプションは自動で付きます。

## 知っておきたいこと

- **GPUが必要です。** NVIDIA GPU（CUDA）またはApple Silicon（Metal）が必要です。CPUだけでは生成できません。
- **初回起動時にタグ説明をダウンロードします。** プロンプトヘルパーのタグ説明のため、Danbooru Wiki韓国語翻訳データを一度取得します。（インターネットが必要なのはこの時だけです）
- **言語はヘッダーで切り替えます。** 右上の`한 / EN / 日`スイッチで切り替えると、設定の説明まで一緒に変わります。
- **更新は自動でお知らせします。** 新バージョンが出たら設定タブからダウンロード・インストール・再起動できます。

## よくある質問

**Q. 無料ですか？**
A. はい。MITライセンスのオープンソースなので、無料で使って改変もできます。

**Q. 作った画像を公開してもいいですか？**
A. アプリ自体はMITなので自由ですが、使ったモデルのライセンスを別途確認してください。モデルごとに商用利用の条件が異なります。

**Q. Windows・macOSでも動きますか？**
A. はい。Linux・macOS・Windowsに対応しています。
