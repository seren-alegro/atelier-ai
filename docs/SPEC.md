# Atelier AI 기획 스펙

작성일: 2026-10-13 / 기획: 세렌

## 0. 프로젝트 성격

- 개인용 프로젝트. 상용화 목적 없음.
- 세렌 본인이 쓰기 좋은 도구를 만드는 것이 목표.

## 1. 제품 정의

WildCanvas(0.1.36) 역공학 분석에서 착안한, 그림 생성 전용 데스크톱 도구.
"기능을 많이 넣은" 도구가 아니라 "쓰기 편한" 도구를 지향한다.

### 핵심 원칙
- 그림 생성에만 집중 (소설/웹툰/TTS/LoRA 학습 제외)
- 이용권/라이선스 서버 없음. 완전 로컬 동작
- Linux + macOS 네이티브 지원 (WildCanvas는 Windows 전용)
- Anima 계열 모델 특화
- Danbooru식 태그 우선 UX

## 2. MVP 범위

### 포함
1. **생성 코어**
   - diffusers 기반 txt2img / img2img
   - Anima 체크포인트 네이티브 지원
   - LoRA 적용
2. **태그 우선 UI**
   - Danbooru 태그 입력 + 자동완성
   - 태그별 한국어 라벨 표시
   - 프롬프트 프리셋 저장/불러오기
3. **모델 매니저**
   - Civitai / HuggingFace에서 직접 다운로드
   - 체크포인트·LoRA·VAE 관리
4. **가이드형 설정 UI** (핵심 차별점)
   - 모든 설정에 한국어 설명 표시
   - 설정마다 추천값 표시 (Anima 기준)
   - 예: CFG 스케일 — "프롬프트 충실도. 높을수록 프롬프트를 빡빡하게 따름"
5. **기본 후처리**
   - 업스케일 (RealESRGAN anime 계열)
   - 인페인트 (1차 포함 — 2026-10-13 확정)
   - 포즈 지정 (ControlNet 계열, 1차 포함 — 2026-10-13 확정)

### 제외 (후순위)
- 소설/웹툰 생성, TTS/오디오북
- LoRA 학습 — 골치 아픈 영역이라 후순위. 넣게 되더라도 추천 세팅(프리셋) 필수
- 클라우드 연동, 계정 시스템

## 3. 아키텍처 (안)

- 백엔드: Python + FastAPI (diffusers 파이프라인)
- 프론트엔드: 웹 UI (Vite 등)
- 데스크톱 래퍼: **Tauri** (2026-10-13 확정. 가벼움 + 크로스플랫폼)
- 참고용 아키텍처만 차용. 코드는 100% 새로 작성 (클린룸)

## 4. 법적 가드레일 (세렌 확정)

- 디컴파일 코드 직접 사용 금지 — 애초에 전부 새로 작성
- UI 문구·에셋 베끼기 금지, 상표명 사용 금지 — 제품명 Atelier AI로 완전히 분리
- 이용권/라이선스 검증 우회 기능 절대 포함 금지 — 이용권 없이 누구나 쓸 수 있게
- 아이디어·구조 수준의 참고만. 리스크는 지지 않음
- ※ 상용 목적이 아니므로 법률 리스크는 낮지만, 클린룸 원칙은 그대로 유지
