# Atelier AI 사용 안내

[English](GUIDE.en.md) · [日本語](GUIDE.ja.md)

## 이 도구는 뭐예요?

Atelier AI는 **그림 생성 전용 데스크톱 앱**이에요. 웹 서비스가 아니라 내 컴퓨터에서 직접 돌아가는 프로그램이라, 생성한 이미지가 외부 서버로 나가지 않아요. 완전 무료 오픈소스(MIT)예요.

이런 분께 맞아요:

- Anime 스타일 그림을 직접 뽑아보고 싶은 분
- 영어 문장보다 **Danbooru식 태그**(`1girl, long hair` 같은)로 프롬프트를 쓰는 분
- Anima 계열 모델을 쓰는 분
- 초보자도 어렵지 않게 쓰고 싶은 분

## 화면 구성

왼쪽 메뉴 여섯 개가 전부예요.

| 메뉴 | 하는 일 |
|---|---|
| 이미지 만들기 | 텍스트 프롬프트로 그림 생성. 배치 큐·X/Y 플롯·Hires Fix도 여기 |
| 이미지 편집 | 인페인트(부분 다시 그리기)·아웃페인팅(캔버스 확장)·포즈 지정 생성 |
| 모델 및 학습 | 체크포인트·LoRA·ControlNet 관리, 내 이미지로 LoRA 학습 |
| 라이브러리 | 마음에 드는 결과물을 모아두는 곳 |
| 작업 기록 | 지금까지의 생성 기록과 설정값 |
| 설정 | 생성 기본값·언어(한국어/English/日本語)·업데이트 |

## 처음 쓰는 흐름

1. **모델 넣기**: 체크포인트(`.safetensors`)를 모델 폴더에 넣어요. 모델 폴더 위치는 설정에서 확인할 수 있어요. 모델이 없어도 앱은 열려요.
2. **프롬프트 쓰기**: 이미지 만들기에서 그리고 싶은 걸 Danbooru식 태그로 적어요. 태그가 막막하면 **프롬프트 도우미**를 펴 보세요. 추천 태그·스타일·구도 칩이 있고, 🔍 검색 탭에서는 한글로 검색하면 영어 태그를 찾아줘요. (`긴 머리` → `long hair`)
3. **생성 버튼**: 한 장씩 뽑아보면서 스텝·CFG·샘플러 값을 조절해요. 모든 설정 항목에 설명과 추천값이 표시돼요.

## 알아두면 좋은 기능

- **배치 큐**: 프롬프트를 최대 200개까지 목록으로 넣으면 한 장씩 순서대로 뽑아줘요. 하나가 실패해도 다음으로 넘어가요.
- **X/Y 플롯**: 샘플러·CFG·스텝·시드를 격자로 비교해 볼 수 있어요. (최대 36칸)
- **Hires Fix**: 작은 그림을 뽑은 뒤 크게 다듬어서 고해상도로 만들어줘요. (단건 생성 전용)
- **얼굴 보정**: 갤러리에서 `✨ 얼굴 보정`을 누르면 얼굴을 찾아 다시 그려줘요.
- **업스케일**: RealESRGAN으로 확대해요. 원본과 섞는 정도를 슬라이더로 조절할 수 있어요.
- **아웃페인팅**: 갤러리에서 `🖼️ 확장`을 누르면 상·하·좌·우로 캔버스를 넓혀줘요.
- **LoRA 학습**: 내 이미지 15~30장으로 캐릭터·화풍 LoRA를 직접 만들 수 있어요. 캡션은 자동으로 달아줘요.

## 알아두면 좋은 점

- **GPU가 필요해요.** NVIDIA GPU(CUDA) 또는 Apple Silicon(Metal)이 있어야 해요. CPU만으로는 생성이 안 돼요.
- **첫 실행 시 태그 설명을 내려받아요.** 프롬프트 도우미의 한국어 태그 설명을 위해 단부루 위키 한국어 번역 데이터를 한 번 받아와요. (인터넷이 필요한 건 이 때뿐이에요)
- **언어는 헤더에서 바꿔요.** 오른쪽 위 `한 / EN / 日` 스위치로 바꾸면 설정 설명까지 함께 바뀌어요.
- **업데이트는 자동으로 알려줘요.** 새 버전이 나오면 설정 탭에서 다운로드·설치·재시작할 수 있어요.

## 자주 묻는 질문

**Q. 무료예요?**
A. 네. MIT 라이선스 오픈소스라 무료로 쓰고 고쳐도 돼요.

**Q. 만든 그림을 공개해도 돼요?**
A. 앱 자체는 MIT라 자유롭지만, 사용한 모델의 라이선스를 따로 확인해 주세요. 모델마다 상업 이용 조건이 달라요.

**Q. Windows·macOS에서도 돼요?**
A. 네. Linux·macOS·Windows를 모두 지원해요.
